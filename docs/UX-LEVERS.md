# UX levers — seller-friendly & daily return

1. **Progress bar 17/17** — visible on Mon véhicule + Menu; completion % sells breadth.
2. **Streak 🔥** — daily open increments streak; loss if day skipped.
3. **Daily XP bonus** — claim CTA; scales lightly with streak.
4. **Module hunt** — each first visit = +25 XP + checkmark; badges at 1/5/10/17.
5. **Menu as shop window** — numbered M1–M17 tiles, short benefit line, « Découvrir · +25 XP ».
6. **Always-on SOS + weather** — safety trust signals (professional, not toy).
7. **Stub banners** — honest “not live” labels protect credibility while demoing scope.
8. **FR default + « Mon véhicule »** — brand/legal label exact; no “Ma voiture”.
9. **Pro + Admin** — B2B upsell surface for garages / operators.
10. **Deep-links Maps/Waze** — instant utility without owning full nav stack.
